# Detecting Outliers Using Z-score

### Problem:

Identify outliers in a dataset using the Z-score method.

### Why 3 is Used as a Threshold?

1. In a normal distribution:
   1. 68% of data falls within ±1 standard deviation
   2. 95% of data falls within ±2 standard deviations
   3. 99.7% of data falls within ±3 standard deviations
2. Values beyond ±3 standard deviations are considered outliers because they are extremely rare (~0.3% probability).
